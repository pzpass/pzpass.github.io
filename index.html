Your secrets, in one encrypted file, on your machine.

PzPass is a minimal password generator and encrypted secret vault. One small binary, no dependencies, no cloud, no hidden behavior — just Argon2id and ChaCha20-Poly1305 from Zig's standard library.

Encrypted vault

Every entry name and value is sealed with ChaCha20-Poly1305 under a random vault key.

Memory-hard KDF

Your master password goes through Argon2id (256 MiB, t=5) before it touches anything.

Interactive TUI

Add, view, edit, delete and search entries from a single-key terminal interface.

Generators built in

Random passwords and diceware passphrases from a 10,399-word list compiled into the binary.

Zero dependencies

Pure Zig, crypto from std.crypto. ~2,200 lines you can actually read.

Local-first

One file under ~/.pzpass/. Back it up, sync it, or don't — your call.

How it works

The only secret you remember is your master password. It's stretched into a key-encryption key, which unwraps the vault key, which decrypts entries one at a time — only the entry you open is ever in plaintext.

  • Changing the password rotates the vault key and re-encrypts every entry.
  • Entry and vault IDs are bound in as AEAD associated data, so ciphertexts can't be swapped between entries or fields.
  • An HMAC-SHA256 over the whole file detects deleted, reordered or duplicated entries.
  • Writes are atomic: .tmp → rename → .bak.
  1. Master passwordonly thing you remember
  2. Argon2id · salt from header
  3. KEKkey-encryption key
  4. ChaCha20-Poly1305 unwrap
  5. Vault keyrandom, never stored in plaintext
  6. ChaCha20-Poly1305 · unique nonce per field
  7. Entriesname & value, decrypted on demand

Install

Prebuilt binaries for Linux x86_64, Linux arm64 and macOS arm64. The binary is called pzp.

brew install meslab/tap/pzpass

Works on macOS and Linux.

TAG=v1.0.1
TARGET=aarch64-macos  # or x86_64-linux, aarch64-linux
curl -fLO "https://github.com/pzpass/pzpass/releases/download/$TAG/pzp-$TAG-$TARGET.tar.gz"
curl -fLO "https://github.com/pzpass/pzpass/releases/download/$TAG/pzp-$TAG-$TARGET.tar.gz.sha256"
shasum -a 256 -c "pzp-$TAG-$TARGET.tar.gz.sha256"
tar -xzf "pzp-$TAG-$TARGET.tar.gz"
mkdir -p ~/.local/bin && install -m 0755 "pzp-$TAG-$TARGET/pzp" ~/.local/bin/pzp

Downloaded with a browser on macOS? Clear the quarantine flag: xattr -d com.apple.quarantine ~/.local/bin/pzp 

git clone https://github.com/pzpass/pzpass.git
cd pzpass
zig build --release=small --prefix "$HOME/.local"

Requires Zig 0.17.0 or later. Without --prefix the binary lands in zig-out/bin/pzp.

Usage

pzp
Open the interactive vault at ~/.pzpass/<USER>.vault.dat.
pzp -f <file>
Open a vault at a custom path.
pzp pass [length]
Generate a random password. Default length 20.
pzp dice [words]
Generate a diceware passphrase. Default 5 words; any key for another, q to stop.

Security notes

  • Passwords and the vault key are never stored in plaintext.
  • All secrets are encrypted at rest with ChaCha20-Poly1305.
  • Key derivation uses Argon2id; parameters are stored per vault so they can be upgraded.
  • Sensitive buffers are mlocked, then zeroed and unlocked when done.
  • Revealed records are wiped from memory; terminal echo is off for every password prompt.
  • Entries are capped at 16 MiB to bound memory use on hostile input.
  • CI audits the source for unsafe patterns on every change.

Known limit

Rolling the vault file back to an older, intact copy is not detected. If that's in your threat model, keep the vault somewhere you control the history of.
